# Red Bull Event Landing Page

An interactive 3D web experience built with **React**, **Three.js** (@react-three/fiber & @react-three/drei), **GSAP ScrollTrigger**, and **Tailwind CSS**.

## Features

- **Interactive 3D Can**: Photorealistic 3D Red Bull can model with dynamic rotation, water droplets, and interactive controls.
- **Scroll-Driven Storytelling**: Choreographed animations synced smoothly using Lenis smooth scrolling and GSAP ScrollTrigger.
- **Atmospheric Visuals**: Egypt pyramids rally raid desert theme with high-performance responsive UI.
- **Audio Feedback**: Interactive sound effects and celebratory confetti micro-interactions.

## Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **3D Graphics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animations**: GSAP, `@gsap/react`, Lenis Smooth Scroll
- **Styling**: Tailwind CSS, Lucide Icons

## Getting Started

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
